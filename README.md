# TEDxCUSAT Landing Page

[➡️ **Live Demo**](https://jithin-joy-arakkal.github.io/TEDxCUSAT-Landing-Page/)

A modern, responsive landing page for the TEDxCUSAT independent event, featuring engaging visual elements and interactive speaker highlights.

## Overview
This project serves as the web entry-point for TEDxCUSAT, providing essential event information, a speakers gallery, and quick actions such as ticket booking. It is designed to be visually appealing, informative, and easy to navigate on both desktop and mobile devices.

## Features
- **Hero Slider:** An animated image slider highlighting key moments and visuals from previous TEDxCUSAT events.
- **Event Info:** Concise details about event theme, venue, and date.
- **About Section:** Context about the TEDxCUSAT initiative, the spirit of TED and its independent organization model.
- **Speakers Gallery:** Horizontally scrollable panel of speaker profiles (draggable on desktop and touch-optimized for mobile) with auto-scroll and pause-on-drag.
- **Responsive Design:** Uses CSS Grid and custom media queries for mobile-friendliness.
- **Quick Navigation:** Prominent calls-to-action for ticket booking and information navigation.

## How It Works
- The landing page is built purely with HTML, CSS, and JavaScript—no backend required.
- The hero image slider cycles through event highlights with smooth animations.
- Speaker profiles are shown in a horizontally scrollable grid. Users can drag to scroll or simply watch the auto-scroll animation.
- Navigation links anchor-scroll to targeted sections: About, Speakers, and Booking.

## File Structure
- `index.html` – Main page markup
- `styles.css` – Core styling for layout and animations
- `script.js` – Controls for hero slider and speaker grid autoscroll/interaction
- `images/` – Event images, logos, favicons

## Getting Started
1. **Clone the repo:**
   ```sh
   git clone https://github.com/jithin-joy-arakkal/TEDxCUSAT-Landing-Page.git
   ```
2. **Open `index.html` in any browser.**

No build tools or frameworks are required. For best results, host with a static file server or on GitHub Pages.

## Customization & Deployment
- To update event info, edit text in `index.html` (event name, date, location).
- Replace images in the `images/` directory for your own events or new speaker profiles.
